The keys below work where their heading says. The quick capture shortcut is the one set in [Settings › General](app:settings/general); `⌃⌥Space` is the default.

## Anywhere
- `⌘K` — Search or jump to anything
- `⌘⇧F` — Search page (also `⌥⌘6`)
- `⌃⌥Space` — Quick capture, from any app
- `⌘N` — New note; `⌘↩` creates it
- `⌘Z` — Undo the last change
- `⌘[` `⌘]` — Back, forward
- `⌥⌘1 … ⌥⌘9` `⌥⌘0` — Today, Inbox, Tasks, Projects, Changes, Search, Ask, Notes, Wiki, Sources
- `⌘,` — Settings
- `?` — Help for this screen
- `Esc` — Clears the screen's search box, wherever the cursor is
- `⇧⌘?` — Brainstead Help (Help menu)
- `⌘Q` — Quit (asks first about unsaved changes)

## A note
- `⌘1` `⌘2` `⌘3` — View, Edit, Source
- `⌘S` — Save
- `⌘F` — Find, and in Edit and Source, replace; `↩` `⇧↩` next, previous match
- `⌘B` `⌘I` `⇧⌘X` `⌘E` `⇧⌘H` — Bold, italic, strikethrough, code, highlight (while editing)
- `⌘=` `⌘-` `⌘0` — Bigger, smaller, usual text size
- `⌘P` — Export PDF
- `⇧⌘P` — Read aloud, then play or pause
- `F8` — Read aloud, or play and pause
- `Space` `Esc` — Play or pause, stop (reading aloud)
- `F7` `F9` — Previous, next paragraph, while reading aloud
- `⇧⌘R` — Rename
- `⌥⌘R` — Reveal in Finder
- `⌥⌘C` — Copy path
- `[[` `#` — Link a note, add a tag (while editing)
- `⌃Space` — Suggestions, in a template's `<% %>` tag
- `↩` `Tab` — Take the chosen suggestion
- `due:` `defer:` `start:` `created:` — A date, then a word: tomorrow, fri, +3d
- `@calls` `effort:15m` — A context and an effort, in a task (and in Quick capture)

## ⌘K
- `↑` `↓` — Move through the results
- `←` `→` — Across the Go to columns (before you type)
- `Tab` `⇧Tab` — Search All, Notes, Wiki or Sources
- `↩` — Run the selected item
- `⌘↩` — Search everything for what you typed
- `Esc` — Close

## Quick capture
- `↩` — Save
- `Tab` — Switch between Task and Thought
- `⇧↩` — New line, in a thought
- `↑` `↓` `↩` `Tab` — Choose and take a suggestion
- `Esc` — Close the suggestions, then the window

## Menu bar window
- `⌘O` — Open Brainstead
- `⌘T` — Open Today
- `⌘J` — Open Ask
- `⌘,` — Open Settings
- `⌘Q` — Quit Brainstead
- `Esc` — Close the window

## Lists
- `↑` `↓` — Move between rows
- `↩` — Open
- `Space` — Quick Look, in the Trash and on a Word, PowerPoint or Excel source

## Task lists
- `↑` `↓` — Choose a task, on into the next list
- `↩` — Open it: its words on Tasks, its note elsewhere
- `Space` — Tick or untick
- `⌫` — Delete it (`⌘Z` puts it back)
- `/` — Search tasks (on Tasks)

## Inbox
- `J` `K` `↑` `↓` — Next, previous item
- `↩` — Accept the suggestion
- `N` `P` `W` — Next action, new project, waiting for
- `2` `S` `R` — Done in two minutes, someday, file as reference
- `⌫` — Delete (a capture: move to the Trash)
- `I` — Ingest into the wiki (a capture)
- `M` — Make a meeting note (a transcript)
- `D` — Draft a reply (a captured email or Teams thread)

## Bookmarks triage
- `K` `I` `T` `A` — Keep, ingest into the wiki, make a task, archive
- `⌫` — Remove the bookmark
- `↩` — Accept the suggestion; remove a missing bookmark

## Changes
- `J` `K` — Next, previous change
- `A` — Accept the held change
- `R` — Reject the held change
- `⌘↩` — Accept every held change in its run

## Ask
- `⌘T` — New chat
- `↩` `⇧↩` — Send, new line
- `Esc` — Stop the answer
- `↑` — An earlier message (in an empty box)
- `→` `Tab` — Type the suggested next message (in an empty box)
- `/` `[[` `#` — A skill, a note, a tag
